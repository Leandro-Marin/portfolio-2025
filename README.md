# Portfolio 2025

Personal portfolio of Leandro Marin — Visual & UX/UI Designer based in Rome.

## Stack
- HTML, CSS, JavaScript
- [Vite](https://vitejs.dev/)
- [GSAP](https://gsap.com/) + [SplitType](https://github.com/lukePeavey/SplitType) for animations

## Getting started
```bash
npm install
npm run dev      # dev server
npm run build    # production build in /dist
npm run preview  # preview the build
```

## Pages
- `index.html` – home
- `about.html` – about me
- `menu.html` – navigation
- `project-*.html` – case studies
