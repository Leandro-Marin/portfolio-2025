# Leandro Marin — Portfolio 2025

Personal portfolio of **Leandro Marin**, Visual + UX/UI Designer from Spain, based in Rome.

🔗 **Live:** [leandro-marin.github.io/portfolio-2025](https://leandro-marin.github.io/portfolio-2025/)

## Concept

*"Playing with colors and fonts."* The site is built around a **Change Mood** button that swaps the whole colour palette of the site on the fly — one click, a new personality. Bold expanded typography, GSAP-powered motion and page transitions keep it playful rather than corporate.

## Features

- **Change Mood** – random colour palettes applied site-wide.
- Animated **loading screen** and **page transitions**.
- Scroll and text animations with **GSAP + ScrollTrigger**.
- Case-study page for each project, About page and downloadable CV.
- Responsive navigation menu.

## Tech stack

HTML5 · CSS3 · Vanilla JavaScript · GSAP 3 (ScrollTrigger) · GitHub Pages
Vite is set up for local development.

## Run locally

```bash
git clone https://github.com/Leandro-Marin/portfolio-2025.git
cd portfolio-2025
npm install
npm run dev
```
